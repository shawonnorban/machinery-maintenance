# Annotech ERP অ্যাপ — ইনস্টল ও প্রথম চালু

এই নির্দেশিকা দুই ভাগে: **ফোনে যিনি অ্যাপ চালাবেন** তাঁর জন্য, আর **IT / অ্যাডমিন**-এর জন্য (সার্ভার, ফোন অনুমোদন, নতুন সংস্করণ)।

---

## ক. ফোনে অ্যাপ বসানো

1. IT-র দেওয়া লিংক বা ফাইল থেকে **`app-release.apk`** ফোনে নামান।
2. ফাইলটা খুলুন। ফোন বললে **"এই উৎস থেকে অ্যাপ বসাতে দিন" (Install unknown apps)** চালু করুন, তারপর **Install**।
3. হোম স্ক্রিনে নীল **A** আইকন — **Annotech ERP** খুলুন।

> পুরনো সংস্করণ থাকলে নতুনটা ওপরেই বসান (আনইনস্টল করবেন না) — না হলে ফোনে জমা থাকা ট্যাপ মুছে যাবে।

## খ. প্রথমবার খুললে

1. **ভাষা বাছুন** — English বা বাংলা (পরে "আরও" পাতা থেকে বদলানো যায়)।
2. লগইন পাতায় উপরে ডানে **⚙** চাপুন → সার্ভারের ঠিকানা দিন:
   - **ইন্টারনেটে (অফিসের বাইরে থেকেও):** `norbanit.com` — পোর্ট **খালি** রাখুন।
   - **কারখানার নিজের Wi-Fi-তে (লোকাল সার্ভার):** সার্ভারের IP, যেমন `192.168.0.10`, পোর্ট `8010`।
3. **"সংযোগ পরীক্ষা"** চাপুন → সবুজ "সংযোগ হয়েছে" এলে **"সেভ"**।

> শুধু IP (যেমন `68.183.88.65`) দিয়ে ইন্টারনেটের সার্ভারে যুক্ত হবে না — সেখানে ডোমেইনই লাগবে।

## গ. লগইন

| কে | কীভাবে |
|---|---|
| **QC** (লাইনের ফোনে) | "QC" ট্যাব → **কোম্পানি কোড** + **এমপ্লয়ি ID** + **৬ অঙ্কের PIN** (প্রথম PIN `000000`, ঢুকে নিজের PIN বসান) |
| **ম্যানেজার / অন্যরা** | "ইমেইল" ট্যাব → **কোম্পানি কোড** + **ইমেইল** + **পাসওয়ার্ড** (ওয়েবের একই) |

**নতুন ফোনে প্রথম QC লগইন:** পর্দায় একটা **৬ অক্ষরের কোড** আসবে ("অনুমোদনের অপেক্ষায়")। ম্যানেজারকে কোডটা বলুন; তিনি অনুমোদন দিলে **"আবার চেষ্টা"** চাপুন।

## ঘ. প্রতিদিনের কাজে মনে রাখার কথা

- **নেট চলে গেলেও** QC-র ট্যাপ আর ব্রেকডাউন রিপোর্ট **ফোনে জমা থাকে**, নেট ফিরলে নিজে চলে যায়। হোমে/ট্যালিতে "সব ট্যাপ পাঠানো হয়েছে" দেখে নিন।
- লাইনের শেয়ার করা ফোনে কাজ শেষে **"লক"** বা **"QC বদল"** চাপুন।
- উপরের বারের ঘণ্টায় নোটিফিকেশন; প্রোফাইলের সবুজ রিং = অনলাইন, লাল = অফলাইন।
- "আপডেট করুন" পাতা এলে আগে ফোনের জমা ট্যাপ চলে যায়, তারপর **"নতুন সংস্করণ নামান"** চাপুন।

## ঙ. IT / অ্যাডমিনের জন্য

**১. সার্ভার**
- ইন্টারনেট: `https://norbanit.com/api/v1/health` ব্রাউজারে খুললে `"status":"ok"` আসা চাই।
- লোকাল: সার্ভারের IP **স্থির (static)** রাখুন, Windows Firewall-এ পোর্ট **8010** খোলা রাখুন।
- লোকাল সংযোগ HTTP (এনক্রিপ্টেড নয়) — শুধু কারখানার নিজস্ব, পাসওয়ার্ড দেওয়া Wi-Fi-তে।

**২. ফোন অনুমোদন** — ওয়েবে **Quality Tally → Phones**: অপেক্ষমাণ ফোনের কোড মিলিয়ে নাম দিন (যেমন "Phone 05") ও **Approve**। হারানো ফোন **Block** করুন।

**৩. QC তৈরি** — **QC Assignment**-এ HR এমপ্লয়িকে সেকশন ও লাইনে দিন; দরকারে **PIN রিসেট**।

**৪. নতুন সংস্করণ চালু করা**
1. নতুন `app-release.apk` সার্ভারে রাখুন (যেমন `https://norbanit.com/app/annotech-erp.apk`)।
2. সার্ভারের `.env`-এ:
   ```
   MOBILE_MIN_VERSION=0.7.0          # এর নিচের অ্যাপ "আপডেট করুন" দেখাবে
   MOBILE_LATEST_VERSION=0.7.0
   MOBILE_DOWNLOAD_URL=https://norbanit.com/app/annotech-erp.apk
   ```
3. `php artisan config:clear` (config cache থাকলে `config:cache`)। ফোনগুলো ১০ মিনিটের মধ্যে বা পরের চালুতে জানবে।

**৫. বিল্ড (ডেভেলপারের কম্পিউটারে)** — `bash mobile/scripts/build.sh release` (APK) বা `bash mobile/scripts/build.sh aab` (APK + Play Store-এর AAB)। সই-এর চাবি `C:\Users\<user>\.annotech-erp\` (`annotech-erp.jks`, `signing.properties`) — **এর ব্যাকআপ রাখুন**; হারালে একই অ্যাপের আপডেট আর দেওয়া যাবে না।
