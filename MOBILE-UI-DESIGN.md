# NORBAN ERP — COMPLETE MOBILE APP UI/UX DESIGN STANDARD

## DESIGN OBJECTIVE

Redesign the entire Norban ERP Mobile Application with a premium, modern, professional Enterprise ERP appearance.

The application should look consistent, clean, elegant, information-rich and easy to operate.

This is a DESIGN-ONLY instruction.

Focus exclusively on:
- Visual Design
- UI Layout
- Typography
- Font Sizes
- Colors
- Spacing
- Component Dimensions
- Cards
- Tables
- Forms
- Badges
- Icons
- Header
- Bottom Navigation
- Buttons
- Modals
- Filters
- Visual Hierarchy
- User Interaction Appearance
- Responsive Visual Behavior

You are responsible for deciding all technical implementation details independently.

---

## 1. OVERALL DESIGN STYLE

Design Direction: Premium Enterprise ERP.

Visual Characteristics:
- Clean and minimal.
- Professional corporate appearance.
- Modern business application.
- White and light-gray surfaces.
- Blue primary color.
- Subtle shadows.
- Thin and consistent borders.
- Compact but readable information.
- Consistent alignment.
- No unnecessary decorative elements.
- No oversized graphical cards.
- No excessive gradients.
- No cartoon-style icons.

The application must look like a professionally designed enterprise business management product.

Use a Light Theme as the standard.

Avoid unnecessary Dark Mode.

## 3. TYPOGRAPHY SYSTEM

Use one consistent professional font throughout the application.

Preferred: Inter.

Typography Standards:

- Main Page Title: 20sp, Bold (700)
- Section Heading: 16sp, SemiBold (600)
- Card Heading: 14sp, SemiBold (600)
- Important Number: 20–24sp, Bold (700)
- Regular Body: 13sp, Regular (400)
- Secondary Information: 12sp, Regular (400)
- Form Label: 12sp, Medium (500)
- Input Text: 13sp, Regular (400)
- Table Header: 12sp, SemiBold (600)
- Table Content: 12–13sp, Regular (400)
- Badge: 11sp, SemiBold (600)
- Button: 13sp, SemiBold (600)
- Helper Text: 11sp, Regular (400)
- Navigation Label: 10–11sp, Medium (500)

Typography Rules:

- Maintain consistent font hierarchy.
- Do not use unnecessarily large text.
- Avoid inconsistent font sizes between similar screens.
- Important values must be visually distinguishable.
- Supporting information must remain subtle.
- Align numerical values consistently.
- Avoid excessive bold text.

## 4. GLOBAL SPACING SYSTEM

Use a consistent 4dp spacing scale.

- Extra Small: 4dp
- Small: 8dp
- Medium: 12dp
- Large: 16dp
- Extra Large: 20dp
- Section Spacing: 24dp

Screen Horizontal Padding: 16dp.

Maintain consistent spacing between all cards, sections, labels, inputs and buttons.

Avoid both overcrowded and excessively spacious layouts.

## 5. HEADER DESIGN

Create a consistent premium mobile header.

Specifications:

- Header Height: 56–64dp.
- Horizontal Padding: 16dp.
- Page Title: 20sp Bold.
- Subtitle: 12sp.
- Back Icon: 22–24dp.
- Notification Icon: 22dp.
- Profile Icon: 24dp.
- Touch Area: Minimum 44dp.

Header must have a clean white or subtle primary-color appearance depending on the screen design.

All modules must use the same header dimensions and visual style.

Page title, subtitle and action icons must be properly aligned.

## 6. BOTTOM NAVIGATION DESIGN

Use a clean, modern bottom navigation design.

Specifications:

- Five primary navigation destinations.
- Navigation Height: 60–68dp excluding system safe area.
- Icon Size: 22–24dp.
- Label: 10–11sp.
- Active Color: #2563EB.
- Inactive Color: #94A3B8.
- Active Background: #EAF1FF.
- Background: #FFFFFF.
- Top Border: #E8EDF5.

Active navigation item must be visually distinguishable.

Avoid oversized icons and excessive navigation decoration.

## 7. CARD DESIGN SYSTEM

Use consistent cards throughout all modules.

Card Specifications:

- Background: #FFFFFF.
- Border: 1dp solid #E8EDF5.
- Border Radius: 14–16dp.
- Internal Padding: 12–14dp.
- Shadow: Very subtle.
- Card Gap: 10–12dp.

Use cards for:
- Dashboard KPIs.
- Budget Records.
- Machine Information.
- Production Summary.
- Stock Information.
- Recent Activities.
- Approval Records.

Cards should be compact, structured and easy to scan.

Do not use unnecessary colorful backgrounds.

## 8. SEARCH & FILTER DESIGN

Search Field:
- Height: 46–48dp.
- Radius: 12dp.
- Font Size: 13sp.
- Search Icon: 19–20dp.
- Background: White.
- Border: #E8EDF5.

Filter Chips:
- Height: 32–36dp.
- Horizontal Padding: 12dp.
- Radius: 18dp.
- Font: 12sp.

Active Filter:
- Blue Background.
- Blue Text.
- Subtle visual emphasis.

Inactive Filter:
- White or Light Gray Background.
- Gray Text.
- Thin Border.

Use horizontal scrolling for filter groups when necessary.

## 9. DATA TABLE & LIST DESIGN

Tables must be compact, professional and readable.

Table Header:
- Font: 12sp SemiBold.
- Background: #F1F5FB.
- Height: 40–44dp.

Table Content:
- Font: 12–13sp.
- Row Height: 48–56dp.
- Divider: #E8EDF5.
- Cell Padding: 8–10dp.

For mobile screens, use structured data cards or compact list layouts instead of forcing wide desktop tables into narrow screens.

Important information must appear first.

Secondary information may be placed beneath the main title.

Use clear visual hierarchy between primary and secondary data.

Standard Icon Sizes:

- Main Module Icon: 24dp.
- Header Icon: 22dp.
- Card Icon: 20dp.

- Small Metadata Icon: 14–16dp.

Avoid mixing filled, outlined, 3D and cartoon-style icon families.

Use consistent icon shapes and visual weights.

Icons must communicate functionality clearly.

## 15. DASHBOARD DESIGN

Dashboard should follow a premium executive mobile dashboard style.

Use:
- Welcome Header.
- Company / Factory Context.
- Notification.
- Module Quick Access Grid.
- Compact KPI Cards.
- Production Summary.
- Operational Alerts.
- Recent Activities.

KPI Cards:
- Label: 11–12sp.
- Value: 20–24sp Bold.
- Supporting Text: 11sp.
- Icon: 20–24dp.

Avoid displaying too many KPIs simultaneously.

Prioritize important operational information.

## 16. MODULE-SPECIFIC VISUAL DESIGN

Maintain the same global design system while adapting each module to its business requirements.

Merchandising:
Clean order cards, buyer information, style details and order status.

Pre-Budget:
Structured budget records, compact costing summaries, clear status badges and approval timeline.

Costing:
Organized calculation sections, clearly aligned numerical values and financial summaries.

Accessories BOM:
Structured item lists, unit information, quantity and costing columns.

Inventory:
Stock cards, quantity emphasis, lot information and stock status.

Production:
Factory and line information, production KPI cards, target-versus-achieved presentation and production trends.

Machinery:
Machine status cards, machine identification, maintenance indicators and service information.

Maintenance:
Service schedules, breakdown records, maintenance history and priority badges.

HRMS:
Employee information cards, attendance summaries and leave status.

Commercial:
Shipment information, document status and export tracking.

Reports:
Clean charts, readable summaries and compact report filters.

Each module must maintain its own functional identity without introducing a different design language.

## 17. EMPTY, LOADING & ERROR STATES

Loading:
Use subtle skeleton placeholders.

Empty:
Use a simple outline icon, concise message and relevant action.

Error:
Use a clear message and retry visual.

Success:
Use subtle green notification.

Avoid oversized illustrations and unnecessary animations.

## 18. RESPONSIVE VISUAL RULES

Support:
- Small Android Phones.
- Standard Android Phones.
- Large Android Phones.
- Tablets.
- iOS where applicable.

Maintain:
- 16dp standard horizontal padding.
- Proper content alignment.
- Readable font sizes.
- Consistent card widths.
- Appropriate spacing.
- Safe-area-aware layout.

Do not stretch components unnaturally on larger screens.

## 19. GLOBAL DESIGN CONSISTENCY RULES

These rules are mandatory across the entire application:

1. Every module must use the same typography system.
2. Every page must use consistent header dimensions.
3. Every card must follow the global card design.
4. Every status must use the centralized badge style.
5. Every form must use consistent input dimensions.
6. Every table must follow the same visual standard.
7. Every button must follow the same button system.
8. Every icon must follow the same icon family.
9. Every page must maintain consistent spacing.
10. Every module must look like part of the same ERP product.

Do not independently redesign individual modules with unrelated visual styles.

## FINAL DESIGN EXPECTATION

The final Norban ERP Mobile App should have a premium, clean, modern and highly professional enterprise appearance.

The design must prioritize:

- Readability.
- Information Hierarchy.
- Compactness.
- Visual Consistency.
- Easy Navigation.
- Efficient Data Entry.
- Professional Appearance.
- Mobile Usability.

Focus only on the visual design and user experience.

Make your own technical and implementation decisions independently.
